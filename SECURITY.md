# Security

This repository is a learning lab, not a deployed service. Nothing here is meant to be exposed to the public internet. Demos and load tests are meant to run against localhost or a local docker-compose stack.

If you find a real security issue in the code itself (not "this demo server has no auth," which is intentional for a lab), open a GitHub issue.

No credentials, API keys, or tokens should ever be committed. Sample env files use placeholder values only.
